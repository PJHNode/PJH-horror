## 변형 사진 (저택이 변하는 연출)

같은 방을 **조금만 바꾼** 사진을 `방이름_alt1.jpg`, `_alt2`, `_alt3` 이름으로 넣으면, 게임이 가끔 원래 사진 대신 몰래 보여줍니다. 아무도 그 카메라를 보고 있지 않을 때 바뀌고, 나중에 다시 보면 원래대로 돌아와 있습니다.

예시:
- `corrA_alt1.jpg`: 초상화 복도인데 액자 속 여자가 사라짐
- `corrB_alt1.jpg`: 하얀 복도 끝 문 하나가 열려 있음
- `nursery_alt1.jpg`: 아이 방 침대에 누가 누워 있음
- `study_alt1.jpg`: 서재 의자가 카메라 쪽으로 돌아가 있음
- `attic_alt1.jpg`: 다락방 곰인형이 사라짐

원래 사진과 구도가 똑같아야 효과가 큽니다. 한눈에 알아보기 힘들 정도로 작게 바꿀수록 더 무섭습니다.

오래된 저택, 폐가, 낡은 가구가 있는 텅 빈 실내 사진이 잘 어울립니다. 가로 사진을 쓰세요. 게임이 알아서 어둡고 흐릿한 CCTV 화면처럼 바꿔 줍니다.
