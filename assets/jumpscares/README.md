# 점프스케어 이미지 넣는 곳

이 폴더에 아래 이름으로 사진을 넣으면 게임이 자동으로 사용합니다.
확장자는 `png`, `jpg`, `jpeg`, `webp`, `gif` 중 아무거나 됩니다.

| 파일 이름 | 나오는 상황 |
|---|---|
| `shadow.jpg` | 그림자 — 왼쪽 문으로 들어올 때 |
| `whisper.jpg` | 속삭이는 여자 — 오른쪽 문으로 들어올 때 |
| `crawler.jpg` | 기어오는 것 — 환기구에서 나올 때 |
| `entity.jpg` | 전력이 바닥난 뒤 어둠 속에서 |

사진이 없으면 코드로 그린 임시 얼굴이 대신 나옵니다.
얼굴이 화면 가운데에 크게 있는 세로/가로 사진이 가장 무섭게 보입니다(화면을 꽉 채우도록 잘려서 나옵니다).
