# 괴물 모습 이미지

카메라와 문 창문에 보이는 괴물의 모습입니다. 이 폴더에 아래 이름으로 넣으면 기본 그림자 대신 사용됩니다.

| 파일 이름 | 괴물 |
|---|---|
| `shadow.png` | 그림자 (왼쪽 문) |
| `whisper.png` | 속삭이는 여자 (오른쪽 문) |
| `crawler.png` | 기어오는 것 (환기구) |
| `doll.png` | 다락방 인형 (CAM 4 다락방에 앉아 있는 모습) |
| `portrait.png` | 초상화 속 얼굴 (카메라 화면을 가득 채우는 얼굴. 투명하지 않아도 됩니다. 없으면 `jumpscares/portrait`를 씁니다) |

- **배경이 투명한 PNG**여야 방 안에 서 있는 것처럼 보입니다. (remove.bg 같은 사이트로 배경을 지울 수 있습니다)
- 전신이 나온 세로 사진이 좋습니다.
- 게임이 자동으로 어둡게, 흐릿하게, 흑백 CCTV 느낌으로 바꿔서 보여주므로 화질이 좋지 않아도 괜찮습니다.
