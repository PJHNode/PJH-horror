# 심야 경비 (PJH Horror)

폐관된 백운 저택 기념관의 야간 경비원이 되어, CCTV로 저택을 감시하며 아침 6시까지 버티는 브라우저 공포 게임입니다.
설치나 빌드 없이 `index.html`만 열면 바로 실행됩니다.

## 플레이 방법

- 한밤중 12시부터 오전 6시까지 살아남으면 그 밤은 클리어입니다. 게임 속 1시간은 실제 1분입니다.
- 모두 5일 밤이며, 밤마다 괴물이 더 빨라지고 전기도 더 빨리 닳습니다.
- 문을 닫고, 불을 켜고, 카메라를 보는 데 모두 전기가 듭니다. 전기가 0이 되면 모든 것이 꺼집니다.

- 게임을 시작하면 전체 화면이 됩니다. `ESC`로 나올 수 있습니다.
- 경비실은 화면보다 넓어서 한 번에 한쪽 문만 보입니다. 문을 여닫거나 불을 켜려면 그쪽을 보고 있어야 합니다.

| 키 | 동작 |
|---|---|
| 마우스를 화면 왼쪽/오른쪽 끝으로, 또는 `←` / `→` | 둘러보기 |
| `SPACE` / `S` | 카메라 올리기 / 내리기 |
| `1`–`9`, `0`(CAM 10) 또는 지도 클릭 | 카메라 바꾸기 |
| `A` / `D` | 왼쪽 / 오른쪽 문 여닫기 (그쪽을 보고 있을 때만) |
| `Q` / `E` | 왼쪽 / 오른쪽 복도 불 (그쪽을 보고 있을 때만) |
| `F` | 환기구에 손전등 비추기 |
| `R` 길게 누르기 또는 버튼 누르고 있기 | 다락방(CAM 4)에서 오르골 태엽 감기 |

## 괴물

- **그림자**: 서재 → 현관 홀 → 초상화 복도 → 응접실 → **왼쪽 문**으로 옵니다. 카메라로 보고 있으면 움직이지 못합니다.
- **속삭이는 여자**: 아이 방 → 현관 홀 → 하얀 복도 → 식당 → **오른쪽 문**으로 옵니다. 카메라로 봐도 멈추지 않습니다.
- **기어오는 것** (2일째 밤부터): 보일러실 → 난방 덕트 → **환기구**로 옵니다. 환기구에 손전등을 비춰 쫓아내야 합니다.
- **다락방 인형**: 다락방의 오르골이 울리는 동안만 잠들어 있습니다. 태엽은 계속 풀리므로 CAM 4에서 감아 주어야 합니다. 다 풀리면 뒤틀린 오르골 소리가 들리고, 그 무엇으로도 막을 수 없습니다. 태엽이 얼마 안 남으면 지도의 CAM 4가 빨갛게 깜빡입니다.
- **초상화 속 얼굴** (2일째 밤부터): 가끔 아무 카메라에 나타나 렌즈를 똑바로 쳐다봅니다. 귀가 울리기 시작하면 바로 다른 카메라로 돌리거나 카메라를 내리세요. 너무 오래 마주 보면 죽습니다.

문 앞에 온 괴물은 불을 켜야만 보입니다. 괴물이 다가온다는 경고는 없습니다. 가끔 들리는 발소리나 속삭임도 진짜일 수도, 아닐 수도 있습니다.

카메라를 보는 동안 문이 열려 있으면 괴물은 조용히 들어와 기다립니다. 카메라를 내리는 순간 눈앞에 있습니다.
괴물이 움직이면 그 카메라는 잠시 "신호 없음"이 됩니다. 괴물 없이 끊기는 때도 있습니다.

저택은 조금씩 변합니다. 아무도 보지 않던 카메라에 아까는 없던 것이 있을 수 있고, 다시 보면 사라져 있습니다. 해치지는 않습니다. 아마도.
밤이 깊어질수록 저택은 당신을 속이려 듭니다. 들리는 것, 보이는 것, 시계까지 믿지 마세요.
