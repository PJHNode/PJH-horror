# 심야 경비 (PJH Horror)

CCTV로 건물을 감시하며 아침 6시까지 버티는 브라우저 공포 게임입니다.
설치나 빌드 없이 `index.html`만 열면 바로 실행됩니다.

## 플레이 방법

- 한밤중 12시부터 오전 6시까지 살아남으면 그 밤은 클리어입니다. 게임 속 1시간은 실제 1분입니다.
- 모두 5일 밤이며, 밤마다 괴물이 더 빨라지고 전기도 더 빨리 닳습니다.
- 문을 닫고, 불을 켜고, 카메라를 보는 데 모두 전기가 듭니다. 전기가 0이 되면 모든 것이 꺼집니다.

| 키 | 동작 |
|---|---|
| `SPACE` / `S` | 카메라 올리기 / 내리기 |
| `1`–`7` 또는 지도 클릭 | 카메라 바꾸기 |
| `A` / `D` | 왼쪽 / 오른쪽 문 여닫기 |
| `Q` / `E` | 왼쪽 / 오른쪽 복도 불 |
| `F` | 환기구에 손전등 비추기 |

## 괴물

- **그림자**: 로비 → 서쪽 복도 → 서쪽 대기실 → **왼쪽 문**으로 옵니다. 카메라로 보고 있으면 움직이지 못합니다.
- **속삭이는 여자**: 로비 → 동쪽 복도 → 동쪽 대기실 → **오른쪽 문**으로 옵니다. 카메라로 봐도 멈추지 않습니다.
- **기어오는 것** (2일째 밤부터): 창고 → 환기 덕트 → **환기구**로 옵니다. 환기구에 손전등을 비춰 쫓아내야 합니다.

문 앞에 온 괴물은 불을 켜야만 보입니다. 괴물이 다가온다는 경고는 없습니다. 가끔 들리는 발소리나 속삭임도 진짜일 수도, 아닐 수도 있습니다.
